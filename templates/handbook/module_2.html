Теория

There is / There are

Конструкция сообщает о наличии предмета или предметов. There is — с исчисляемым существительным в единственном числе и с неисчисляемыми; there are — с исчисляемыми во множественном числе.

ФормаЕдинственное числоМножественное числоНеисчисляемое
УтверждениеThere is a server in the room.There are five computers here.There is some information on the disk.
ОтрицаниеThere isn't a printer here.There aren't any cables on the desk.There isn't much space on the drive.
ВопросIs there a monitor on the table?Are there any files in the folder?Is there any Wi-Fi here?

Краткие ответы: Yes, there is. / No, there isn't. — Yes, there are. / No, there aren't. В утверждениях чаще используется some, в отрицаниях и вопросах — any.

This / These / That / Those

Указательные местоимения различаются по двум признакам: число (единственное/множественное) и дистанция (рядом/далеко).

Рядом (here)Далеко (there)
Единственное числоthis — This is a laptop.that — That is a data center.
Множественное числоthese — These are keyboards.those — Those are old servers.
Разбор примеров
01a folder / desktop
There is a folder on the desktop.
02no printers / office (отрицание)
There aren't any printers in the office.
03five monitors / server room
There are five monitors in the server room.
04this laptop (рядом) / that server (далеко)
This laptop is fine, but that server needs an update.
05any Wi-Fi / here? (вопрос)
Is there any Wi-Fi here?
