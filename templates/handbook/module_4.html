Теория

Чистый код и рефакторинг

Чистый код — это код, который легко читать и менять: понятные имена, короткие функции, каждая из которых отвечает за одно действие. Рефакторинг — это изменение внутреннего устройства кода без изменения его поведения снаружи: программа продолжает делать то же самое, но становится проще и надёжнее.

The Zen of Python

Философию языка можно увидеть прямо в интерпретаторе — команда import this печатает 19 принципов PEP 20. Несколько из них особенно важны для этого модуля:

Beautiful is better than ugly.Красивое лучше уродливого.
Explicit is better than implicit.Явное лучше неявного.
Simple is better than complex.Простое лучше сложного.
Errors should never pass silently.Ошибки не должны замалчиваться.
Readability counts.Читаемость имеет значение.

compare_numbers_v2.py
def read_rational(prompt: str) -> float:
    """Запрашивает число у пользователя, пока ввод не станет корректным."""
    while True:
        raw_value = input(prompt).strip().replace(",", ".")
        try:
            return float(raw_value)
        except ValueError:
            print("Ошибка: введите число, например 3.5 или -2")


def compare_numbers(a: float, b: float) -> str:
    """Возвращает словесный результат сравнения a и b."""
    if a == b:
        return "a равно b"
    return "a больше b" if a > b else "a меньше b"


def safe_ratio(a: float, b: float) -> str:
    """Вычисляет a / b, безопасно обрабатывая деление на ноль."""
    if b == 0:
        return "не определено (деление на ноль)"
    return f"{a / b:.4f}"


def main() -> None:
    a = read_rational("Введите число a: ")
    b = read_rational("Введите число b: ")

    print(f"Результат сравнения: {compare_numbers(a, b)}")
    print(f"Разность a - b = {a - b:.4f}")
    print(f"Отношение a / b = {safe_ratio(a, b)}")


if __name__ == "__main__":
    main()
