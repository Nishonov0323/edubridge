АудиторияУчащиеся старших классов и студенты 1 курса IT-направлений
ЯзыкРусский, с англоязычным модулем
Формат4 модуля: теория → разбор примеров → задания
ИнструментыТетрадь, Python 3

Назначение пособия

Идея
Показать, что арифметика рациональных чисел, грамматика технического английского и запись алгоритма — три взгляда на один и тот же навык: точно формализовать условие и довести его до проверяемого результата.
Структура
Каждый модуль состоит из трёх блоков: «Теория», «Разбор примеров» и «Задания для самостоятельной работы» с ключом ответов.
Сквозная связь
Числа, посчитанные вручную в Модуле 1, становятся тестовыми данными для программы в Модуле 3, а её код дорабатывается в Модуле 4.
Код
Все примеры на Python оформлены по стандарту PEP 8: осмысленные имена, докстринги, ограничение длины строки.
