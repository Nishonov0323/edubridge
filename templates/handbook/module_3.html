Теория

Элементы блок-схемы

Каждая фигура на блок-схеме имеет строго закреплённое значение:

Овал — начало / конец
Параллелограмм — ввод / вывод
Прямоугольник — процесс / действие
Ромб — условие (да / нет)

Путь от задачи к коду

  1. Сформулировать условие задачи словами.
  2. Выделить исходные данные и ожидаемый результат.
  3. Расписать шаги алгоритма словесно или псевдокодом.
  4. Изобразить блок-схему, используя фигуры выше.
  5. Перевести каждый блок в код на Python: параллелограмм → input()/print(), ромб → if, прямоугольник → присваивание или вычисление.
  6. Протестировать программу на нескольких наборах данных, включая «пограничные» случаи.
Разбор примеров

Задача: сравнение двух рациональных чисел

Даны два числа a и b. Нужно определить, какое из них больше, и вывести результат сравнения.

compare_numbers.py
def compare_numbers(a: float, b: float) -> None:  # объявляем функцию с двумя параметрами
    """Сравнивает два рациональных числа и печатает результат."""  # докстринг — что делает функция
    if a > b:                        # ромб: a больше b?
        result = "a больше b"       # ветка «да» — запоминаем текст результата
    elif a < b:                      # ромб: a меньше b?
        result = "a меньше b"      # ветка «да» — запоминаем текст результата
    else:                              # иначе остаётся случай a == b
        result = "a равно b"       # числа равны — запоминаем текст результата

    difference = a - b                # вычисляем разность чисел
    ratio = a / b                     # вычисляем отношение (во сколько раз a больше/меньше b)

    print(f"Результат сравнения: {result}")  # печатаем текстовый результат
    print(f"Разность a - b = {difference}")  # печатаем разность
    print(f"Отношение a / b = {ratio}")  # печатаем отношение


if __name__ == "__main__":            # выполняется только при прямом запуске файла
    a = float(input("Введите число a: "))  # считываем и переводим число a
    b = float(input("Введите число b: "))  # считываем и переводим число b
    compare_numbers(a, b)          # вызываем функцию с введёнными числами
Внимание Эта версия падает с ошибкой ZeroDivisionError, если b = 0, и с ValueError, если ввести не число. Это не случайный недосмотр: обе проблемы мы осознанно устраним в Модуле 4 — на примере одной и той же программы виден весь путь от рабочего, но хрупкого кода к устойчивому.
